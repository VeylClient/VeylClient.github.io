Questions

FAQ.

What is Veyl?

Veyl is an aesthetics-focused Fabric Minecraft client. It is mainly built around visual effects, customization and improving the visual experience, while also including some non-aesthetic visual features and a few client-side utilities.

What makes Veyl different?

Skins+ is one of Veyl's more unique features. It uses Minecraft skin layers to create animations on your skin, alongside a broad set of visual and cosmetic modules.

What does Veyl require?

Veyl uses Fabric and Fabric API.

Which Minecraft versions are supported?

Veyl supports Minecraft versions 1.20.1 - 26.3.

Where can I find the source code?

The Veyl source code is available through the Source Code button in the navigation and hero section.
